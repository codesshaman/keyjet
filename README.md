# Usage

### Installing:

```
git clone https://github.com/codesshaman/keygen.git
```

```
cd keygen
```

Change file with yourth parameters (example):

HOST_NAME="gitlab"
HOST_ADDRESS="gitlab.com"
KEY_NAME="gitlab_deploy"

```
nano keygen
```

```
chmod a+x keygen
```

```
sudo cp keygen /usr/local/bin
```

### Command for runing:

```
keygen
```
